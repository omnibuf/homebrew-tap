# OmniBuf Homebrew Tap (`omnibuf/tap`)

Official Homebrew formulas for the [OmniBuf](https://omnibuf.com) CLI and Go `protoc` code generator.

## Install

```bash
# Install the jq-style omnibuf CLI and conformance runner
brew install omnibuf/tap/omnibuf

# Install the protoc / buf Go code generator plugin
brew install omnibuf/tap/protoc-gen-omnibuf
```

## Upgrade

```bash
brew update
brew upgrade omnibuf protoc-gen-omnibuf
```
